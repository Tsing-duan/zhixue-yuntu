# AI 模型接入与运行边界

**简体中文** · [English](ai-model-setup.en.md) · [项目介绍](../README.md)

本文依据当前仓库实现编写。平台有六个生成接口，共用 `DeepSeekClient`；**不是任意 OpenAI 兼容服务的通用适配器**。目前代码限定官方 `https://api.deepseek.com`、模型 `deepseek-v4-flash`、`reasoning_effort=high`，使用 `/chat/completions`、非流式输出和 thinking enabled。不要在 URL 后加 `/v1`。更换 provider、模型或协议需要修改适配器和契约测试，不能仅修改环境变量。

模型名称是仓库当前锁定的值，不是对供应商可用性或价格的承诺。本轮只验证本机模拟服务与未配置分支，未发起真实模型调用。

## 从未配置状态开始

1. 先按 [README 本地 Demo](local-development.md) 准备专用数据库、Redis、Java 和前端。AI 依赖现有登录身份及 Redis；不能脱离平台认证直接访问。
2. `.env` 不存在时运行 `umask 077; cp .env.example .env`，已有文件则直接编辑，避免覆盖。填写数据库配置及不少于 32 字符的 `JWT_SECRET`。可用 `openssl rand -hex 32` 生成 JWT 密钥，勿把输出贴到文档或工单。
3. 不用 AI 时保持 `DEEPSEEK_API_KEY=`，或设置 `DEEPSEEK_ENABLED=false`。登录、课程等普通功能可正常使用；生成请求返回清楚的未配置/已关闭提示，不伪造答案、不保存成功历史。
4. 需要真实 AI 时，由部署者从自己的 DeepSeek 账号取得凭据，在本机 `.env` 编辑器里填写 `DEEPSEEK_API_KEY` 并设 `DEEPSEEK_ENABLED=true`。不要将密钥放到前端、命令行参数、截图或提交中。建议 `chmod 600 .env`；`.env` 已由 Git 忽略。
5. `bash scripts/start-demo.sh` 会通过后端脚本加载 `.env` 并构建启动。当前脚本针对 macOS Temurin 17。手动 `java -jar` 不会自动读取 `.env`，需通过部署环境注入变量（或在可信本地 shell 中 `set -a; source .env; set +a`）。环境变更需重启后端；不要在共享业务环境直接运行演示初始化 SQL。

当前隔离预览 `127.0.0.1:14001` / `14000` 使用独立后端 `18080`，其启动脚本强制清空 AI Key；编辑根目录 `.env` 不会给该预览开启真实调用。

## 环境变量

| 变量 | 默认值 | 作用 / 范围 |
| --- | --- | --- |
| `DEEPSEEK_ENABLED` | `true` | `false` 关闭生成；即使有密钥也不请求供应商 |
| `DEEPSEEK_API_KEY` | 空 | 只放在后端环境；空值不发送请求 |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | 普通运行仅允许此官方 HTTPS 根地址 |
| `DEEPSEEK_MODEL` | `deepseek-v4-flash` | 当前唯一允许值 |
| `DEEPSEEK_REASONING_EFFORT` | `high` | 当前唯一允许值 |
| `DEEPSEEK_MAX_TOKENS` | `4096` | 输出上限，整数 1–8192；越大预留额度越多 |
| `DEEPSEEK_CONNECT_TIMEOUT_MS` | `5000` | 1–30000 毫秒 |
| `DEEPSEEK_READ_TIMEOUT_MS` | `120000` | 1–180000 毫秒；不自动重试 |

无效地址、模型或数值在初始化时拒绝，即使 AI 关闭也应保留合法配置。仅 Spring `test` profile 允许本机 HTTP 模拟服务，生产不要启用该 profile。

## 功能与数据范围

| 功能 | 授权与资料 | 生成要求 |
| --- | --- | --- |
| 学习问答 | 已登录三角色；当前问题，不自动带入聊天上下文 | 学科解释、例子、自检；条件不足先澄清 |
| 学习计划 | 学生自己的已报名课程、章节观看/作业完成记录 | 1–90 天、每周 1–60 小时，任务、时长、产出及复习安排 |
| 错题分析 | 学生自己的作业/考试答题记录；最多 20 道 | 区分学生答案与参考答案；错因有依据，缺题干或选项明确说明 |
| 课程总结 | 学生仅已报名课程及自己的进度；教师仅自己的课程；管理员可访问课程 | 区分目录概览与内容总结；不把观看当掌握，不虚构视频内容 |
| 教师备课 | 教师自己的课程；管理员可访问课程 | 10–240 分钟，目标、活动、形成性评价，活动总时长受限 |
| 教学数据分析 | 教师自己课程/考试或管理员权限范围 | 说明样本与范围，区分事实、假设、建议，不凭单期数据声称趋势 |

界面语言通过 `Accept-Language` 传递，服务端给新生成回答增加中文或英文输出要求；原始参考资料和已保存回答保持原文。这是提示词约束，不保证供应商每次完全遵循。

课程等文本与用户补充要求作为资料传入，不能决定角色或授权。角色、课程归属与学生身份由服务端判断。提示词没有数据库写入、浏览器或自动提交作业能力。关键词检查只拦截部分明显滥用；不能保证模型永远遵守提示词。

## 额度与日志

| 角色 | 每日调用 | 每日 token 预算 | 两次请求最短间隔 | 单次任务输入字符上限 |
| --- | --- | --- | --- | --- |
| 学生 | 30 | 20,000 | 15 秒 | 1,000 |
| 教师 | 60 | 60,000 | 8 秒 | 2,500 |
| 管理员 | 100 | 120,000 | 5 秒 | 4,000 |

所有功能共用账号额度。输入上限包含服务器组合的任务说明；任务与资料合计最多 16,000 字符。调用前预留“资料字符估算 + 配置输出上限 + 系统提示余量”，成功后按供应商 usage 结算。估算不是精确 tokenizer，也不是货币消费上限；应同时在供应商侧设置预算。

Redis Lua 原子执行每日额度、冷却和单账号在途请求检查；多后端实例共享同一个 Redis。删除聊天历史不会返还额度；历史中的当日成功用量作为迁移下限。失败请求保守保留次数和预留 token，避免失败重试刷接口；关闭或缺少密钥不计费，但仍保留短暂冷却。Redis 不可用时拒绝发起模型请求；超时/崩溃后的锁按租约过期，旧请求不能释放新锁。

生产 Redis 需持久化、访问控制和容量保障：清空/丢失 Redis 会丢失未保存在成功历史中的保护额度。当前演示 Redis 没有持久化。每日边界按后端系统时区；多实例应统一时区。

管理端“成功次数/token”来自成功历史，与保守的防滥用账本不同。失败不写成功历史。成功答案与所用资料会保存到当前用户的 AI 历史；只有用户本人可查看/删除。传给供应商的学习资料应避免包含密钥或无关个人信息。

默认 MyBatis 使用 NoLoggingImpl，关闭会输出数据库参数和历史正文的 SQL 调试。AI 接口日志不保存问题/回答/资料正文、Key、Authorization 或隐藏推理；异常日志仅记录异常类型。Provider 日志仅含状态、耗时和 token 等元数据。不要为排查问题打开 HTTP wire/header/body 日志。

## 如何验证

无付费调用的契约回归（本机 HTTP mock）：

```sh
mvn -f learn_server-master/pom.xml -pl ape-admin -am test
```

覆盖六个入口、学生课程总结、越权课程、非法参数、额度拒绝、模型错误/超时、关闭/未配置零请求、成功 usage 和最终内容校验。`scripts/verify-ai-quota.py` 额外检查 Lua 的并发、归属、失败预留和额度边界；只允许运行在已有隔离演示 Redis 16379，测试键自动清理。

真实调用需要部署者明确启用并承担供应商费用：登录对应角色，选择自己有权访问的课程，只提交一次小任务，检查非空最终答案、历史记录和 token 统计。检查完可设置 `DEEPSEEK_ENABLED=false` 并重启。401/403 凭据错误、402 余额不足、429 限流、超时、缺少 usage 或不完整答案会显示失败，不伪造成功或自动重试。不能用 mock 通过替代真实供应商验收。
